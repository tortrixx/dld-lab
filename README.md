# 简易拼图游戏的设计与实现

> 《数字电路与逻辑设计实验（下）》综合课题 · **题目 4**
> 目标器件：**Altera MAX II `EPM1270T144C5`** · 开发工具：**Quartus II 9.1** · 设计语言：**VHDL**

---

## 项目简介

在 MAXII 数字逻辑实验开发板上，用 VHDL 实现一个基于 **8×8 双色点阵**的简易拼图游戏。

玩家在 5 秒内观察完整拼图图案，随后图案被打散成若干块零片随机散落在点阵上；
玩家用 4×4 矩阵键盘选择零片、移动到正确位置并确认，在倒计时结束前还原完整图案即获胜。

**游戏共两关：**

| | 第一关 | 第二关 |
|---|---|---|
| 完整图案 | 4×3 实心矩形（题目指定） | 自拟图案 |
| 零片数量 | 3 块 | 4 块 |
| 预览时间 | 5 秒 | 5 秒 |
| 拼图限时 | 30 秒 | 40 秒 |

---

## 功能要求

### 基本要求（已全部纳入实现范围）

1. **SW7 系统开关** —— 关断时所有显示器件熄灭、蜂鸣器静音；开启后进入开机自检：点阵全黄 2Hz 闪烁，8 位数码管全显"8" 且 2Hz 闪烁
2. **待机状态** —— 2 秒后点阵熄灭，DISP7 显"5"、DISP0 显"1"
3. **两关制** —— 关卡号由数码管 DISP0 显示
4. **图案预览** —— 按"开始"后点阵显示完整图案 5 秒，DISP7 倒计时
5. **零片散落** —— 预览结束后 3 块零片随机不重叠散落，DISP4/DISP3 开始 30 秒倒计时
6. **选择零片** —— "选择"键循环切换，选中的零片变绿
7. **移动零片** —— "上/下/左/右"键移动，不得移出 8×8 区域
8. **确认落位** —— "确认"键后零片变黄并锁定，不可再选、不可再动
9. **第一关判定** —— 30 秒内拼对进入第二关；拼错或超时显示失败图案，游戏结束
10. **第二关** —— 规则同上，图案与零片自拟，限时 40 秒；成功显示胜利图案
11. **重新开始** —— 游戏过程中或结束后按"开始"键可重开一局

### 提高要求（选择性实现）

- ✅ 不同场景播放不同音效（蜂鸣器）
- ✅ 多种拼图图案随机选择
- ✅ 零片初始位置随机
- ⬜ 零片 90°旋转（不实现）
- ⬜ 零片方向随机（不实现）

## 系统架构

顶层 `puzzle_top` 例化 9 个子模块：

| # | 模块 | 职责 |
|---|---|---|
| 1 | `clk_gen` | 时钟分频与节拍产生 |
| 2 | `keypad_scan` | 4×4 矩阵键盘扫描 + 消抖 + 边沿检测 |
| 3 | `seg_scan` | 8 位数码管动态扫描 + BCD 译码 |
| 4 | `dot_matrix_scan` | 8×8 双色点阵动态扫描 |
| 5 | `pattern_rom` | 图案与零片形状掩码存储 |
| 6 | `rng_lfsr` | 伪随机数发生器 |
| 7 | `puzzle_ctrl` | 零片位置 / 选择 / 移动 / 锁定 + 匹配判定 |
| 8 | `game_fsm` | 游戏主状态机 |
| 9 | `buzzer_ctrl` | 蜂鸣器音效 |
| — | `puzzle_top` | 顶层，唯一做引脚绑定的文件 |

详细框图与接口定义见 `docs/01-系统设计.md`。

## 开发环境

| 项 | 值 |
|---|---|
| 开发板 | MAXII 数字逻辑实验开发板（LCM12864 液晶版） |
| 器件 | EPM1270T144C5（MAX II，144 脚 TQFP，C5 速度等级） |
| 工具 | Quartus II 9.1 |
| 仿真 | Quartus II 内置仿真器（`.vwf` 向量波形激励） |
| 时钟 | 板载可选，本项目使用 **50MHz**（档位 7） |

## 构建

```bash
# 全流程编译
quartus_sh --flow compile quartus/puzzle

# 分步执行
quartus_map quartus/puzzle      # 综合
quartus_fit quartus/puzzle      # 布局布线
quartus_asm quartus/puzzle      # 汇编
quartus_tan quartus/puzzle      # 时序分析
```

烧录见 `CLAUDE.md` §5.2。
