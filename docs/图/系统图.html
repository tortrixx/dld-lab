① 拼错

全部零片都按下「确认」锁定后，若零片掩码的并集 ≠ 目标图案，立即判失败， 不等倒计时走完。判据是并集而不是逐块比对——因为三块零片恰好有 2 种合法铺法，逐块比对会把其中一种正确解误判为失败。

② 超时

倒计时归零时仍有零片未锁定。第一关 30 秒、第二关 40 秒， 倒计时器直接用两位 BCD 递减，因此综合结果里不会出现十进制除法器。

导入方式

浏览器打开本文件 → 右键图形 → 另存为 SVG，或在 draw.io 里选 File ▸ Import 直接导入这个 HTML 里的 SVG 源码。 导入后每个矩形框、每条箭头都是独立可编辑对象，不是一张位图。

为什么不做成深色

两张图在明暗两种主题下都画在白纸上。这些图最终要导出 PNG 贴进实验报告， 而报告是要打印的——白底深线才印得清楚。

改图规矩

框图里一个矩形框 = 一个 .vhd 文件 = 一个实体。 改了模块接口就必须同时改这张图和 docs/01-系统设计.md 的接口表——老师会照着图抽模块提问。
